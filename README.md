# TCR-Snniper
un software sencillo tipo herramienta de recortes para el texto de imagenes o videos con el motor Tesseract-OCR
Requisitos Previos
1. Python 3.8+
2. Motor Tesseract OCR

Windows: Descarga e instala el ejecutable desde Tesseract at UB Mannheim.
Nota importante: Asegúrate de instalar los paquetes de idioma para Español (spa) e Inglés (eng) durante la instalación, y verifica que Tesseract se instale en la ruta por defecto (C:\Program Files\Tesseract-OCR) o que esté añadido a las variables de entorno (PATH) de tu sistema.
